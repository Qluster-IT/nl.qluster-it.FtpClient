FTP 서버의 파일을 살펴보고 Homey에서 파일 전송을 자동화하세요. 카메라 스냅샷을 저장하거나, NAS에 보고서를 보내거나, 호환되는 플레이어에서 오디오 파일을 사용할 수 있습니다.

• Homey에서 파일 관리: 파일을 업로드하고 다운로드하거나, 폴더를 만들고 파일과 폴더의 이름을 바꾸거나 이동 및 삭제할 수 있습니다.
• Flow로 자동화: 이미지나 base64로 인코딩한 파일을 저장하고, 파일 목록을 JSON으로 가져오고, Flow에 이미지를 불러오거나 임시 다운로드 링크를 만들 수 있습니다.
• 연결 상태 확인: Homey가 설정한 폴더를 자동으로 확인합니다. FTP에 연결할 수 없거나, 연결이 복구되거나, 전송에 실패할 때 Flow를 실행할 수 있습니다.

FTP Client 기기를 추가하고 서버 정보를 입력하세요. 페어링할 때는 보안 FTP(FTPS)를 먼저 시도하고, 필요한 경우 암호화되지 않은 FTP를 사용합니다. 시작 폴더를 선택하면 파일 탐색과 Flow의 파일 작업이 해당 폴더 안에서만 이루어집니다. 기기의 복구 화면을 열면 Homey 앱이나 웹 앱에서 파일을 탐색할 수 있습니다.

Micro Web Server를 포함한 FTP 서버와 함께 사용할 수 있습니다.
