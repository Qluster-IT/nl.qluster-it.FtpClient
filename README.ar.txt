تصفّح الملفات على خادم FTP وأتمت عمليات النقل من Homey. احفظ لقطات الكاميرات أو أرسل التقارير إلى وحدة التخزين الشبكي (NAS) أو أتح ملفات صوتية لمشغّل متوافق.

• أدر الملفات من Homey: ارفع الملفات ونزّلها وأنشئ المجلدات وأعد تسمية الملفات والمجلدات أو انقلها أو احذفها.
• أتمت المهام باستخدام Flow: احفظ الصور أو الملفات المرمّزة بصيغة base64، أو احصل على قوائم الملفات بصيغة JSON، أو حمّل الصور إلى Flows، أو أنشئ روابط تنزيل مؤقتة.
• احفظ الملفات من عناوين URL: انقل التنزيلات عبر HTTP أو HTTPS أو FTP إلى خادمك، بما في ذلك روابط التصدير من Simple (Sys) Log، دون تمرير الملف عبر رمز Flow.
• دعم Simple (Sys) Log: احفظ صادرات CSV أو Excel أو JSON باستخدام بطاقة التصدير المخصصة، أو صِل بطاقة عنوان URL للتصدير ببطاقة «حفظ ملف من عنوان URL» للسجلات الكبيرة.
• راقب الاتصال: يتحقق Homey تلقائيًا من المجلد المحدد. شغّل Flows عند تعذّر الوصول إلى FTP أو عودة الاتصال أو فشل نقل ملف.

أضف جهازًا من نوع «اتصال FTP» وأدخل بيانات الخادم. عند الاقتران، يحاول Homey استخدام FTP الآمن (FTPS) أولًا ويلجأ إلى FTP غير المشفّر عند الحاجة. إذا اخترت مجلد بدء، فسيقتصر تصفّح الملفات وعمليات الملفات في Flows على ذلك المجلد. افتح شاشة إصلاح الجهاز لتصفّح الملفات في تطبيق Homey أو تطبيق الويب.

يعمل مع خوادم FTP، بما فيها Micro Web Server.

يتطلب تطبيق Better Logic Library. تدعم الحقول النصية لاسم الملف والمسار كتابة أكواد BLL. راجع إعدادات تطبيق Better Logic Library لمعرفة كيفية استخدام أكواد BLL.

لمزيد من المعلومات، اطّلع على موضوع التطبيق في منتدى مجتمع Homey.
للوصول إلى ويكي FTP Client ودليل المستخدم، اختر «زيارة الموقع الإلكتروني» ضمن «موقع المطوّر» في صفحة التطبيق على Homey App Store.
