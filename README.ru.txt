Просматривайте файлы на FTP-сервере и автоматизируйте их передачу из Homey. Сохраняйте снимки с камер, отправляйте отчёты на сетевое хранилище или открывайте аудиофайлы в совместимом проигрывателе.

• Управляйте файлами в Homey: загружайте и скачивайте файлы, создавайте папки, переименовывайте, перемещайте и удаляйте файлы и папки.
• Автоматизируйте задачи с помощью Flow: сохраняйте изображения и файлы в кодировке base64, получайте списки файлов в формате JSON, загружайте изображения в Flow или создавайте временные ссылки для скачивания.
• Сохраняйте файлы по URL: передавайте загрузки по HTTP, HTTPS или FTP на свой сервер, включая ссылки на экспорт Simple (Sys) Log, без передачи файла через токен Flow.
• Поддержка Simple (Sys) Log: сохраняйте экспорт в CSV, Excel или JSON с помощью специальной карточки экспорта или соедините его карточку URL экспорта с «Сохранить файл по URL» для больших журналов.
• Следите за подключением: Homey автоматически проверяет выбранную папку. Запускайте Flow, когда FTP становится недоступен, снова доступен или передача завершается ошибкой.

Добавьте устройство типа «FTP-соединение» и укажите данные сервера. При подключении Homey сначала пробует защищённый FTP (FTPS), а при необходимости использует FTP без шифрования. Если выбрать начальную папку, просмотр и операции с файлами в Flow будут ограничены этой папкой. Откройте экран восстановления устройства, чтобы просматривать файлы в приложении Homey или в браузере.

Работает с FTP-серверами, включая Micro Web Server.

Требуется приложение Better Logic Library. Код BLL поддерживается в текстовых полях имени файла и пути. Инструкции по использованию кода BLL доступны в настройках приложения Better Logic Library.

Дополнительную информацию можно найти в теме приложения на форуме сообщества Homey.
Чтобы открыть вики и руководство пользователя FTP Client, нажмите «Посетить сайт» в разделе «Сайт разработчика» на странице приложения в Homey App Store.
